# 321Team

**321Team**은 [코오롱 베니트] 하이브리드 클라우드 컨테이너 플랫폼 설계 및 구현 9기 과정의 프로젝트 팀입니다. 본 과정은 Red Hat과 AWS 환경을 기반으로 한 국비 지원 클라우드 부트캠프입니다.

이 페이지는 공개 소개용입니다. 내부 설계 정본, 실행 증적, IP·인증 정보, 운영 절차는 비공개 저장소에서만 관리합니다.

## 무엇을 만드나

교육 과정에서 하이브리드 클라우드 컨테이너 플랫폼을 설계·구현하고, 그 위에 **FDS(이상거래탐지) 서비스**를 올리는 팀 프로젝트를 수행합니다.

공개적으로 말할 수 있는 구성은 다음과 같습니다.

- On-prem 성격의 가상화 기반 인프라와 컨테이너 오케스트레이션
- 거래 API(`transaction-api`)와 탐지 엔진(`fds-engine`) 애플리케이션
- 외부 관리형에 준하는 PostgreSQL 데이터 계층
- 컨테이너 레지스트리·취약점 스캔, 관측(모니터링), CI/CD를 포함한 플랫폼 서비스

완성된 상용 제품 공개나 Runtime 인수 완료를 이 소개가 대신하지 않습니다. 문서 정본은 비공개 저장소의 승인된 태그/Release를 기준으로 합니다.

## 공개 범위

- 과정명, 팀 소개, 구축 중인 플랫폼·서비스의 개요는 공개합니다.
- 내부 주소, 계정, 인증서, 비밀, 미공개 설계서, 실행 로그는 공개하지 않습니다.
- 조직의 작업 저장소는 비공개입니다. 이 `.github` 저장소만 조직 프로필을 위해 공개합니다.
